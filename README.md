# marham-app-testing
QA testing project for the Marham mobile application, including manual test cases, bug reports, usability suggestions, and Appium automation testing.

## Project Overview

This project contains the QA testing activities performed on the Marham mobile application.
The project covers manual testing, test case design, bug reporting, usability testing, suggestions for improvement, and mobile test automation using Appium with Python.

## Testing Areas

- Appointment Booking
- In-Clinic Visits
- Video Consultation
- Doctor Search
- Lab Tests
- User Profile
- Personal Information
- Mobile Number Validation
- Friends & Family
- Other major user journeys

## Manual Testing

Manual testing activities include:

- Functional Testing
- Exploratory Testing
- Positive Testing
- Negative Testing
- Validation Testing
- Usability Testing
- Regression Testing

## Test Cases

Test cases were created with:

- Test Case ID
- Module
- Feature
- Test Scenario
- Preconditions
- Test Steps
- Expected Result
- Actual Result
- Status
- Priority
- Explanation

## Bug Reporting

Identified bugs were documented with:

- Bug ID
- Module
- Bug Description
- Steps to Reproduce
- Expected Result
- Actual Result
- Severity
- Priority
- Status
- Supporting Screenshots

## Suggestions

Usability and improvement suggestions were also documented based on the testing experience and user perspective.

## Automation Testing

Mobile automation testing was performed using:

- Python
- Appium
- Appium Inspecter
- Node.js
- Android Studio/ Real Device

Automation test cases were created to validate important mobile application flows.
